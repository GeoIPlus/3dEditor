Design [A, this WP]:
- Roots: the kernel dir (`config.kernel.dir`) plus every `services/<name>/package.json` in the scanned files.
- Root deps from the root's `package.json`: `dependencies`, `optionalDependencies`, `peerDependencies`
  (devDependencies out of scope). Transitives from the lockfile entries, resolved the npm way
  (`<from>/node_modules/<name>`, then each parent, then the repository root); `link` entries are followed.
- Fail closed: no lockfile while a root has runtime dependencies, a root missing from the lockfile, a dependency not
  in the lockfile (unless optional), or no licence -> problem.
- SPDX expression: `OR` passes if any alternative passes, `AND` needs all; `WITH` exceptions are not allowed (not in
  the list). GPL/LGPL/AGPL named in the message.
- Scope out: Q-43 (EPSG data terms) is a data licence, not a code licence; this check does not decide it.
