Design (proposal, owner approval D-18):
- One file per schema `contracts/model3d/<name>.schema.json`, `$id` `urn:geoiplus:schema:model3d-<name>:v1`.
- Shared `$defs` in `common` (ids, V2, V3, Line3, Plane, enums); payloads one file per kind
  `command-payload-<kind-kebab>`; `command` dispatches `payload` by `operation` (if/then per kind).
- Model and command sides can be approved as two groups in one dialog (avoids an intake split of the L row).
