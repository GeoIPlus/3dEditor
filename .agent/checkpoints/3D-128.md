## Plan
Port `datasets` (3D-ADR-0003 §1, §4): `read(ref)` -> bytes + strong entity tag; `save(ref, bytes, ifMatch)` whole-body
`PUT` + `If-Match` -> `saved` (new tag) | `precondition-failed` (412); `putDelivered(p, bytes)` / `readDelivered(p,
digest)` content-addressed, write-once. Service function `saveResult` (no tag -> not sent, `NO_ENTITY_TAG`; 412 ->
`KEPT`, bytes kept in the own store) and `deliveredAddress` (https, no query, no credential).
File adapter: append-only generations per dataset (`{n}.bin`, tag `"{n}.{sha256}"`); a save is the exclusive create of
generation `n+1`, so `If-Match` is a compare-and-swap without overwriting (D-84, D-85; same pattern as `history`).
