### How a task is run [V: `claude -p` probe 2026-11-20 in this container]
- Headless Claude Code CLI 2.1.330: `claude -p <prompt> --output-format stream-json --verbose`. Probe: a one-word reply
  cost $0.096 (11.4k cache-create + 26.8k cache-read tokens = the bare system prompt), so the fixed cost per run is real.
- Start state: `git clone --local` of the ref under test (default `HEAD`) into a scratch dir; `origin` re-pointed to a
  local bare repo so pushes are harmless and observable; optional `setup.mjs` per task applies the scenario (e.g. a WP
  row set `in-progress`, a failing golden test, a 290-line file). The clone carries AGENTS.md, CLAUDE.md, `.claude/`
  (skills, hooks) of the ref under test: that is what is measured.
- Isolation: `--strict-mcp-config` (no MCP: no GitHub, no session creation), `--permission-mode bypassPermissions`
  inside the throwaway clone, `--max-budget-usd` cap per run, `--no-session-persistence`; same model as WP sessions
  (recorded per run from the result event).
- Owner dialog in headless mode: AskUserQuestion is graded from the tool_use input in the transcript (2-4 options,
  first marked "(Recommended)"); the run is not answered, so tasks are graded on what the agent does up to that point.
  To be verified in the pilot run.
- Captured per run: final text, tool calls (name + input), `git diff --stat` + changed files vs. start, pushes seen by
  the bare remote, result event usage (`total_cost_usd`, tokens, `num_turns`, `duration_ms`).

### How a task is graded
- `rubric.mjs` per task: a list of deterministic checks `{id, weight, desc, check(run)}` over the captured run
  (files changed, file contents, tool calls, final text). Score = passed weight / total weight, 0-1. No LLM judge in the
  baseline (cost and its own noise); a check that needs judgement is written as a narrow textual check and marked
  `[weak]` in the rubric, so its false passes are visible.
- Comparison rule (D-27, §7.8): a task "holds" when both runs score >= its threshold; an instruction change is kept only
  if no task flips from holding to not holding.
