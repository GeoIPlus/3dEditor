# 3D-13 checkpoint

## Plan

Module `packages/geo-model3d/src/solve/` (imports `brep` only, `tools/check-arch/config.mjs:40`). Approach fixed by
[3D-ADR-0005](../../docs/decisions/adr/3D-ADR-0005-solver-approach.md) (D-110): stage 1 closed form per plane with
objective O1, stage 2 Gauss-Newton / LM over all movable planes with hard constraints as linearised equalities (null
space), conflicts by Jacobian rank + deletion filter, underconstrained by null space not fixed by the objective.

Two layers, so that the numeric core does not depend on open per-kind semantics:
- **Conditions** (plane terms, the solver's own language): residual functions of the movable plane parameters, each
  tagged with the constraint id it comes from. Point-on-plane (fixed point), derived-vertex-at-point / on-fixed-plane /
  on-line / equal-Z, normal relations (parallel, perpendicular, horizontal, vertical, slope angle), soft weighted terms.
- **Compiler**: model `Constraint` entities (contract `building-model` `Constraint`) -> conditions. Kinds whose meaning the
  spec states are compiled; the others need the per-kind semantics of Q-3D13-1 (owner) and stay `TBD` until answered.
