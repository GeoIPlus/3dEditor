Design notes:
- RESIZE_ROOF: roof planes P_i (non-OVERHANG RoofSurface of the body); precondition: lower envelope of P_i over the
  current roof plan reproduces each face (cell of P_i = {z_i <= z_j}) within planarTolM, else INVALID_TOPOLOGY
  (D-391); installations joined to the roof -> INVALID_TOPOLOGY. Cells over the convex outline = half-plane clipping.
  true: footprint := outline, `buildEnvelope` with the cells, roof face ids kept. false: footprint kept; each footprint
  edge with outline offset w > 0 must be a structural eave -> `addOverhang(width w)` (overhang.js), else D-344.
- ALIGN_WALL: change only the wall supportPlane; re-derive vertices; update footprint ring; existing overhang on the
  wall / its end walls: removeOverhang before, addOverhang after with the same width (as set-height.js EAVE).
