baseline; requests go in as body bytes through `commandBody` (size limit, JSON parse), reply `JSON.stringify`.
Stages from injection points the API offers: `parse` (readJsonBody `parse`), `validateCommand` / `validateReply`
(wrapped `deps.contracts`), `loadModel` (wrapped store reads), `serialize`; the kernel and API logic is the remainder
(`kernelAndApi`) - `executeCommand` is imported by commit.js, not injectable. Injected ms clock advances 100 ms per
request (a 10 Hz drag), so the D-316 rate limit (20/s) admits every request and still runs.
