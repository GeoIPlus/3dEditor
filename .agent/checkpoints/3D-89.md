Method (as implemented):
- History: every commit reachable from HEAD (`git rev-list HEAD`, all parents, so side-branch commits count with their own
  date) whose tree has `docs/BACKLOG.md`; blobs read through one `git cat-file --batch`, each distinct blob parsed once.
- Universe = rows of the current status table. First appearance of an id = earliest committer date (UTC day) of a
  commit whose table holds it; first `done` = earliest such commit with status `done`. A merge commit cannot count a row
  twice: a row is one id with one date (minimum over commits).
- Baseline = earliest commit with BACKLOG.md; plan period = baseline day .. baseline day + 13; plan end = baseline + 14 d.
- Growth window = [max(today - 14, plan end), today]; added = rows first appearing in it, finished = rows first `done`
  in it. Before the plan end, g is not measured: the block says so and ETC shows known x k only (provisional D-253).
- Throughput keeps the 14-day window (clipped to the backlog's age) and counts rows first `done` in it.
