### Design (readings marked [A] go to the module card)
- Public: `validateModel(model, options) -> Promise<ValidationReport>` (async because FINAL awaits the port).
  Options: `mode`, `targetState`, `tolerances` (contract tolerance profile), `clock` (ISO string), `affectedEntityIds?`,
  `fullSolid?`, `findings?`, `externalValidator?` (FINAL only). Internal sync `runChecks` / `newIssues` for `ops`.
- `isValidForTargetState`: FAST_PREVIEW always false (v0.2 §16.2 "does not confirm"); otherwise no ERROR issue.
- Severity for `DRAFT_SURFACE` -> DRAFT_SOLID column, `APPROVED` -> VALID_SOLID column (D-3D12-6).
- Scope per code [A] table; mapping of brep structural problems and val3dity codes to `ValidationCode` [A] - Q-3D12-1.
- "New" issue: no issue of the same code in the previous report whose entity ids, mapped through lineage, meet the
  current issue's ids [A]. The contract has no `isNew`; newness is an internal result for the commit gate (rule 7).
- `validatorVersion`: `geo-model3d-validate/1`, FINAL `...+<port version>` [A].
