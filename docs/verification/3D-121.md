# 3D-121 verification note: server PREVIEW latency through the command API

Date 2026-11-26, branch `wp/3d-121-bench-real-path`. Raw output: [3D-121/bench.json](3D-121/bench.json)
(`npm run bench -- --json`). Rig and protocol: [3D-ADR-0006](../decisions/adr/3D-ADR-0006-bench-rig-and-scenes.md)
Decision 1-4 (D-111). Path: `createCommandApi` (services/kernel/src/command-api.js, 3D-109) over
`createHistory(createMemoryStore())` (D-357), every request through `commandBody`; the kernel runs once per PREVIEW
(D-355). The 3D-08 numbers ([3D-08.md](3D-08.md)) measured the MOVE_EDGE spike and stay as history.

## Verdict

**Target met.** Gate scene sawtooth-199 (199 faces): server PREVIEW **p95 56.106 ms** pooled over 5 x 1000 requests
after 300 warm-up, worst run p95 56.859 ms, every reply a PREVIEW; target p95 <= 150 ms (v0.3 §11). No escalation
(D-06). Against the spike path (3D-08 p95 5.411 ms; 3D-109 re-run 5.037 ms) the real path is about 10x slower; the
headroom to 150 ms is about 2.7x on this rig, not on the production class (Q-42, 3D-110).
